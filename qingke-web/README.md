# 轻刻 Web

轻刻 (Qingke) 是一个开源的待办任务管理工具，此 Web 版完全复刻了 [Android 版本](https://github.com/zhuyao-opendeveloper/qingke) 的界面和功能。

## 功能

- **任务管理**: 创建、编辑、完成、删除任务，支持优先级、截止日期
- **多视图**: 收件箱 / 今天 / 未来7天 / 某天 筛选
- **项目分类**: 将任务归类到不同项目中
- **标签系统**: 为任务添加标签方便检索
- **日历视图**: 月视图 / 年视图，直观查看任务分布
- **番茄钟专注**: 25分钟专注计时，支持短休/长休
- **习惯打卡**: 创建习惯，每日打卡，追踪连续天数
- **倒计时**: 记录重要日期的倒计时
- **看板视图**: 待办 / 进行中 / 逾期 卡片管理
- **四象限**: 艾森豪威尔矩阵管理任务优先级
- **时间线**: 按日期组织的任务列表
- **AI 聊天**: 智能助手对话式管理任务
- **搜索**: 全文搜索任务
- **数据管理**: 导出/导入备份，本地存储
- **深色模式**: 支持浅色/深色主题切换

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无外部依赖，单页应用
- localStorage 本地数据持久化
- 移动优先的响应式设计
- 支持 PWA 安装到桌面

## 开发

无需构建工具，直接在浏览器中打开 `index.html` 即可运行。

## 部署

本仓库通过 GitHub Actions 自动部署到 GitHub Pages。

每次推送到 `main` 分支且修改了 `qingke-web/` 目录时，会自动触发部署。
